# Scraper data notes

- Source of truth is the official dex at bandai.co.jp/candy/pokemonscaleworld/lineup/. It lags months behind, so products it doesn't list come from the Bandai Candy brand page (`BRAND_LIST`, `?__offset=20...`); their figures get `x<product>_<n>` ids and are matched to existing figures by character + label. Their photos come from the product page gallery (`figure_photo`: Premium Bandai = group shot + 3 views per figure; candy = one photo per numbered box, split into one crop per figure). A brand-page figure that is a new sculpt of a character already in the dex with the same label (Lumiose City Chikorita) needs an entry in `NEW_SCULPTS`, or it is merged into the old figure. When an `x` id disappears (the official dex now lists the figure), the scraper writes `idAliases` (old → new id, from the previous `scaledex.json`) and the UI moves owned / wishlist marks over; never remove old aliases. Fix wrong picks in `FIGURE_IMAGES` and wrong left-to-right order in `FIGURE_CROPS`; a figure with no photo of its own gets one from `FIGURE_PHOTO_URLS` (Premium Bandai's image server `bandai-a.akamaihd.net/bc/img/model/b/<item>_<n>.jpg` isn't region-blocked and has more views). Figures without an official height get `heightEst` (PokeAPI height at 1:20). Home-card figures are hand-picked in `REGION_PICKS` (`app/dex.js`). New trainers there need an entry in `NEW_TRAINERS` and a role in `TRAINER_ROLES` (the scraper warns when one is missing). Trainer display order comes from Bulbapedia's "List of Trainer figurines" (`bulbapedia_trainer_order`). Each lineup id (`025`, `025_2`, `470_hisui`) is one figure; figures are grouped into characters by dex number (Pokémon) or id prefix (trainers).
- p-bandai.jp blocks non-Japanese IPs. Premium Bandai prices and ship dates come from the Wayback Machine (`id_` raw snapshots, JSON-LD `price`). Keep archive.org requests slow (`ARCHIVE_DELAY`).
- Trainer English names are mapped by hand in `TRAINERS`; product names are machine-translated from Japanese with `PRODUCT_WORDS` + character names. Add to those tables when new lines appear.
